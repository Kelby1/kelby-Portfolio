# Kelby Portfolio — V2 Interactive Tech Hero

React + Vite portfolio with an interactive networking / systems hero.

## What's new in V2

- Interactive network map in the hero
- Clickable Support / Network / Systems / Printer / Web nodes
- Dynamic terminal-style readout
- Mouse tilt/parallax on desktop
- Animated network packets and node pulses
- Moving technical signal strip
- Stronger hover states for services, skills, and timeline entries
- Reduced-motion accessibility fallback
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

No company name or logo has been introduced yet. This version stays personal and portfolio-first.
